# Term Explainer

Chrome Extension (Manifest V3) ไฮไลต์ศัพท์เฉพาะในหน้าเว็บ (เช่น "Manifest V3") แล้ว Claude จะสรุปให้ว่าคืออะไรในกล่องเล็กๆ ใกล้คำนั้น

## ติดตั้งเพื่อทดสอบ
1. เปิด `chrome://extensions` และเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
3. คลิกขวาที่ไอคอน extension → **ตัวเลือก (Options)** → ใส่ Anthropic API key → บันทึก
4. เปิดเว็บใดก็ได้ (หน้าที่เปิดค้างอยู่ก่อนติดตั้งต้อง refresh) แล้วลากเมาส์เลือกคำ

## วิธีทำงาน
- `content.js` ตรวจจับการเลือกข้อความ (ไม่เกิน 80 ตัวอักษร / 8 คำ) แล้วแสดง tooltip ใน Shadow DOM
- ส่งคำที่เลือกพร้อมข้อความรอบข้างสั้นๆ (เพื่อเดาความหมายให้ถูก) ไปที่ `background.js`
- `background.js` เรียก Claude Messages API (`https://api.anthropic.com/v1/messages`) แล้วส่งคำอธิบายกลับ มี cache ในหน่วยความจำกันเรียกซ้ำคำเดิม
- `options.html/js` ตั้งค่า API key, โมเดล และภาษาของคำอธิบาย

## ข้อควรรู้
- ทุกครั้งที่เลือกคำ จะมีการเรียก API ซึ่งมีค่าใช้จ่ายตามการใช้งาน
- ข้อความที่เลือกและข้อความรอบข้างสั้นๆ จะถูกส่งไปที่ Anthropic อย่าใช้กับหน้าที่มีข้อมูลลับ
- API key เก็บใน `chrome.storage.local` ของเบราว์เซอร์คุณเอง ไม่ใช่ในโค้ด
- กด Esc, คลิกที่อื่น หรือเลื่อนหน้า เพื่อปิด tooltip
