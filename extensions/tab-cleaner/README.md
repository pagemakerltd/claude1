# Tab Cleaner

Chrome Extension (Manifest V3) นับแท็บที่เปิดอยู่ทุกหน้าต่าง และปิดแท็บที่ซ้ำกันในคลิกเดียว

## ติดตั้งเพื่อทดสอบ
1. เปิด `chrome://extensions` และเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
3. เปิดเว็บเดียวกันหลายแท็บ → กดไอคอน extension → กด **ปิดแท็บที่ซ้ำ**

## กติกาการหาแท็บซ้ำ
- ถือว่าซ้ำเมื่อ URL เหมือนกัน (ไม่นับส่วน `#hash`)
- แต่ละ URL เก็บไว้ 1 แท็บ โดยเลือก: แท็บที่กำลังใช้งาน > แท็บปักหมุด > แท็บแรกสุด

## โครงสร้าง
- `manifest.json` – การตั้งค่า (ใช้ permission `tabs` เพื่ออ่าน URL ของแท็บ)
- `popup.html/css/js` – แสดงสถิติและปุ่มปิดแท็บซ้ำ
