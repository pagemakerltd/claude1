# Web Pet (โหมดทามากอต) — สเปกภาพที่ต้องสร้าง

เอกสารนี้ใช้ส่งต่อให้นักวาดหรือใช้เป็นพื้นฐานเขียน prompt ให้เครื่องมือสร้างภาพ AI
ครอบคลุมตัวละครทุกขั้นการเติบโต ท่าทางทั้งหมด ไอคอนสถานะ ของใช้ และภาพสำหรับขึ้นร้านค้า

> สถานะปัจจุบัน: มี "แมวลายสลิดโต" 1 ตัว ครบ 13 แถบภาพ (94 เฟรม) ใช้เป็น **ตัวอ้างอิงสไตล์** ของทุกตัวที่เหลือ
> ไฟล์อ้างอิง: `images/cat/*.png` (แถบภาพที่ตัดแล้ว) และแผ่นภาพต้นฉบับที่ใช้ตัด

## 1. ภาพรวมที่ต้องสร้าง

| หมวด | รายการ | จำนวนโดยประมาณ |
|---|---|---|
| ก. ตัวละคร (ขั้นการเติบโตและร่างวิวัฒนาการ) | ไข่, ลูกแมว, แมวรุ่น, แมวโต 6 ร่าง (มีอยู่แล้ว 1) | 9 ตัวใหม่ |
| ข. ท่าทางของแต่ละตัว | ชุดหลัก 8 ท่า + ชุดเสริม 7 ท่า | 38 เฟรม/ตัว (หลัก), +36 (เสริม) |
| ค. เอฟเฟกต์ | แปลงร่าง, ฟักไข่, หัวใจ, ประกาย ฯลฯ | ~60 เฟรม |
| ง. ไอคอนสถานะและ UI | แถบสถานะ, อาหาร, ของเล่น, บ้านหลายแบบ, ของแต่งตัว | ~50 ชิ้น |
| จ. ภาพสำหรับขึ้นร้าน Chrome Web Store | ไอคอน, ภาพหน้าจอ, ภาพโปรโมต | ~10 ชิ้น |

ทำเป็นขั้น ตามหัวข้อ 9 (ลำดับความสำคัญ)

## 2. สไตล์ภาพ (ต้องตรงกันทุกตัว)

คงสไตล์เดียวกับแมวลายสลิดที่มีอยู่

- **รูปแบบ:** พิกเซลอาร์ตแบบ chibi น่ารัก หัวใหญ่ตัวเล็ก ตาโตกลมมีไฮไลต์ ปากเล็ก แก้มชมพู
- **เส้นขอบ:** เส้นขอบสีเข้ม (น้ำตาลเข้มเกือบดำ) หนาสม่ำเสมอ เห็นเม็ดพิกเซลชัด ไม่เบลอ ไม่ใช้ anti-alias แบบนุ่มเกินไป
- **สี:** พาเลตจำกัด (ตัวละครหนึ่งตัวไม่เกิน ~16 สี) โทนอบอุ่น พาสเทล หูด้านในชมพู
- **แสง/เงา:** ลงเงาแบบ 2 ระดับ (สีหลัก + เงา) ไม่มีเกรเดียนต์นุ่มๆ
- **ทิศทาง:** ตัวละครทุกท่า **หันไปทางขวา** (โค้ดกลับด้านเองเมื่อเดินไปทางซ้าย) ยกเว้นท่าหน้าตรง/หันหลังที่ตั้งใจ
- **ความสม่ำเสมอของตัวละคร:** ลายขน สี รูปหู หาง ต้องเหมือนกันทุกเฟรมของตัวนั้น
- **เส้นฐาน (baseline):** เท้าของตัวละครทุกเฟรมในชุดเดียวกันต้องอยู่ระดับแนวนอนเดียวกัน ยกเว้นท่าที่ตั้งใจให้ลอย (กระโดด) เพื่อให้เวลาเล่นแอนิเมชันตัวไม่สั่น
- **พื้นหลัง:** โปร่งใส (PNG alpha) ถ้าเครื่องมือทำไม่ได้ ให้ใช้ **สีขาวล้วน #FFFFFF เรียบ** ไม่มีเงา เกรเดียนต์ หรือพื้นลาย (ผมลบพื้นหลังขาวออกเองได้)
- **เงาใต้เท้า:** วงรีสีเทาจางๆ ใต้ตัว (อย่างที่ใช้ในท่าวิ่ง/กระโดดของแมวตัวปัจจุบัน) หรือไม่มีเลยก็ได้ แต่ต้องเหมือนกันทั้งชุด
- **ห้าม:** ข้อความ ลายน้ำ ลายเซ็น กรอบ พื้นหลังฉาก ตัวละครมีลิขสิทธิ์ของผู้อื่น

## 3. ขนาดและรูปแบบไฟล์

### 3.1 แผ่นภาพ (sprite sheet) ที่ส่งให้ผมตัด
- ขนาดแผ่น **1536×1024 px ขึ้นไป** (หรือ 2048×1365 ได้ ยิ่งใหญ่ยิ่งคมเมื่อย่อ) ไฟล์ PNG/WebP
- จัดเป็น **แถว** แต่ละแถว = 1 ท่า เฟรมเรียงซ้ายไปขวาตามลำดับเวลา
- เว้นระยะระหว่างเฟรมอย่างน้อย **24 px** (ผมตัดเฟรมโดยตามช่องว่าง ถ้าเฟรมติดกันจะตัดผิด)
- เว้นช่องว่างระหว่างแถวอย่างน้อย **30 px**
- ป้ายชื่อท่า (เช่น `IDLE`, `WALK`) ใส่ได้ ให้เป็นกล่องสีฟ้าอ่อนมุมซ้ายบนของแต่ละแถวอย่างที่แผ่นแมวตัวเดิมทำ (ผมรู้จักและตัดทิ้งได้) แต่ถ้าไม่ใส่ จะง่ายกว่า
- เอฟเฟกต์ (หัวใจ ประกาย ?, !) วาดอยู่ใกล้ตัวละครในเฟรมเดียวกัน ห่างจากเฟรมข้างเคียงเกิน 24 px
- ตัวละคร 1 ตัวต่อ 1–2 แผ่น (แผ่นชุดหลัก + แผ่นชุดเสริม) ตัวละครคนละตัวคนละแผ่น เพื่อให้สไตล์ไม่ปนกัน

### 3.2 ขนาดตัวละครในแผ่น (วัดที่แผ่น 1536×1024) — ให้เห็นความต่างของขั้นการเติบโต

| ขั้น | ความสูงตัว โดยประมาณ | ความกว้างตัว โดยประมาณ |
|---|---|---|
| ไข่ | 70 px | 55 px |
| ลูกแมว | 65 px | 70 px |
| แมวรุ่น | 85 px | 90 px |
| แมวโต (ทุกร่าง) | 90–110 px | 100–120 px |

ร่างพิเศษที่ตัวใหญ่/กลม (เช่น แมวนักกิน) กว้างได้ถึง 135 px

## 4. รายการตัวละคร (ต้นไม้วิวัฒนาการ)

```
ไข่ ──(ฟัก ~ 30 นาที–1 ชม.)──> ลูกแมว ──(3 วัน)──> แมวรุ่น ──(7 วัน, ตามการดูแล)──> แมวโต
                                                                              ├─ A. แมวลายสลิด (สมดุล)      ← มีแล้ว
                                                                              ├─ B. แมวดาว (ดูแลดีเยี่ยม)
                                                                              ├─ C. แมวนักกิน (ให้อาหารบ่อย)
                                                                              ├─ D. แมวนักเล่น (เล่นบ่อย)
                                                                              ├─ E. แมวจันทร์ (นอนบ่อย)
                                                                              ├─ F. แมวจรจัด (ถูกละเลย)
                                                                              └─ G. แมวทอง (ลับ: ดูแลดีต่อเนื่อง 30 วัน)
```

เงื่อนไขและเวลาเป็นแนวทางเริ่มต้น ปรับได้ตอนเขียนโค้ด **ภาพไม่ขึ้นกับตัวเลขเหล่านี้**

### ลักษณะของแต่ละตัว (ใช้เขียน prompt)

| รหัส | ชื่อ | ลักษณะ | จุดเด่นที่ต้องเห็นชัด |
|---|---|---|---|
| E0 | **ไข่** | ไข่ขนาดกลาง ลายจุดสีน้ำตาลอ่อนบนเปลือกครีม มีไฮไลต์ | ไม่มีตา ไม่มีขา ขยับด้วยการโยกและสั่น มีรอยร้าวค่อยๆ เพิ่ม |
| B0 | **ลูกแมว** | ตัวเล็กกลม หัวใหญ่ หูเล็ก ลายสลิดจางๆ หางสั้น ตาโตเป็นประกาย | เดินโซเซ ตัวตุ้ยนุ้ย ดูไร้เดียงสา |
| Y0 | **แมวรุ่น** | ตัวเริ่มยาว ขาเรียวขึ้น หูตั้ง ลายสลิดชัดขึ้น หางยาวปานกลาง | ท่าทางซุกซน อยู่ระหว่างลูกแมวกับตัวโต |
| A | **แมวลายสลิด (สมดุล)** | ตัวที่มีอยู่แล้ว | — |
| B | **แมวดาว** | แมวลายสลิดแต่หน้าตาสดใสเป็นพิเศษ สวมหมวกแก๊ปสีกรมท่ามีดาวทอง ผ้าพันคอสีทอง ประกายดาวลอยรอบตัว | โทนกรมท่า-ทอง คล้ายชุดของกระต่ายในภาพก่อนหน้า |
| C | **แมวนักกิน** | ตัวอ้วนกลมกว่าตัวปกติ แก้มป่อง สวมผ้ากันเปื้อนและหมวกเชฟเล็กๆ | ท้องกลม ยิ้มกว้าง มีกลิ่นหอมลอย (ควันอาหาร) |
| D | **แมวนักเล่น** | ตัวเพรียว คล่องแคล่ว คาดผ้าที่หัว มีพลาสเตอร์ที่จมูก ข้อเท้ามีสายรัดกีฬา | ท่าทางพร้อมวิ่ง ไหมพรมคล้องหาง |
| E | **แมวจันทร์** | ตาปรือง่วง ขนสีเทาอมม่วงจางๆ สวมหมวกนอน (nightcap) ปลายมีพู่ ถือหมอนใบเล็ก | โทนม่วง-ฟ้าเข้ม มีพระจันทร์เสี้ยว/ดาวลอย |
| F | **แมวจรจัด** | ขนยุ่งไม่เรียบ หูข้างหนึ่งแหว่ง ตาเหนื่อยๆ ผอมกว่า มีรอยเปื้อน | **ยังน่ารัก** ไม่น่ากลัวหรือน่าสงสาร เกินไป (ผู้ใช้ไม่ควรรู้สึกผิด) |
| G | **แมวทอง** | ลายสลิดเป็นสีทองเหลือบรุ้ง มีออร่าประกายตลอดเวลา สวมมงกุฎเล็กๆ | ภาพลับ ดูพิเศษที่สุดในชุด |

## 7. ไอคอนสถานะ ของใช้ และ UI

ทั้งหมดเป็นพิกเซลอาร์ตสไตล์เดียวกัน พื้นโปร่งใส ส่งเป็น sheet รวมก็ได้ (ผมตัดให้)

### 7.1 ไอคอนสถานะ (ขนาด 32×32 px และ 16×16 px ชุดละ 2 สถานะ: เต็ม / หมด)
- 🍖 ความหิว (ปลา/กระดูกปลา)
- ❤️ ความสุข (หัวใจ)
- ⚡ พลังงาน (ดาว/สายฟ้า หรือ z)
- ✨ ความสะอาด (ประกาย/ฟองสบู่)
- 🌡️ ป่วย
- 😴 หลับอยู่
- ⭐ ระดับความสนิท (5 ระดับ)
- แถบหลอดสถานะ (bar) พื้นหลังหลอด + ส่วนเติม 3 สี (เขียว/เหลือง/แดง)

### 7.2 อาหาร (48×48 px ต่อชิ้น)
ปลา, ปลากระป๋อง, ปลาทูตัวโต, ถ้วยอาหารเม็ด, ชามนม, ขนมแมวเลีย, เค้กวันเกิด (พิเศษ), ของที่ไม่ควรกิน (เพื่อทำอารมณ์ขัน) เช่น ผัก

### 7.3 ของเล่น (48×48 px ต่อชิ้น)
ไหมพรมแดง (ใช้อยู่ ปัจจุบันเป็น emoji), ลูกบอลมีกระพรวน, หนูของเล่น, ไม้ตกแมวมีขนนก, ตุ๊กตาปลา, ปากกาเลเซอร์ (จุดแดง), กล่องกระดาษ

### 7.4 บ้านและที่นอน (ขนาดประมาณ 112×100 px ต่อหลัง วาด 2 แบบ: ว่าง / มีแมวนอน)
บ้านไม้ (มีอยู่แล้วเป็น SVG), กล่องกระดาษ, ที่นอนกลมสีชมพู, เต็นท์ผ้า, บ้านปราสาทเล็ก (ปลดล็อก), บ้านกลางคืน (มีหน้าต่างเรืองแสง)

### 7.5 ของแต่งตัว (วางทับตัวละครได้ ต้องออกแบบให้พอดีทุกขั้นการเติบโต)
หมวกแก๊ป, หมวกเชฟ, หมวกนอน, มงกุฎ, โบว์, แว่นตา, ผ้าพันคอ, ปลอกคอมีกระดิ่ง, ปีกนางฟ้า — แต่ละชิ้นวาด 3 มุม: หน้าตรง, เฉียงขวา, ด้านข้าง

### 7.6 UI อื่นๆ
- **กรอบการ์ดสมุดภาพ** (ตัวละครที่เคยเลี้ยง) กรอบหนึ่งแบบปกติ + เงาตัวดำ (ยังไม่ปลดล็อก)
- **ตรา (badge) ความสำเร็จ** 10 ชิ้น เช่น เลี้ยงครบ 7 วัน, ให้อาหาร 50 ครั้ง, ได้ครบทุกร่าง
- **เงาดำของตัวละคร** แต่ละตัว (silhouette) สำหรับสมุดภาพ "???" (ผมทำจากภาพจริงให้ได้ ไม่ต้องวาด)
- **ปุ่มเมนูลัด** (💬 📝 🌐 🏠 + ใหม่: 🍖 ให้อาหาร, 🛁 อาบน้ำ, 🎮 เล่น) ขนาด 24×24 px สไตล์พิกเซล

## 8. ภาพสำหรับขึ้น Chrome Web Store

## 9. ลำดับความสำคัญ (ทำเป็นรอบ)

### รอบ 1 — MVP (ได้เล่นทามากอตจริง)
| ตัวละคร | ชุดที่ต้องทำ |
|---|---|
| ไข่ | `egg_idle`, `egg_shake`, `egg_hatch` (16 เฟรม) |
| ลูกแมว | ชุดหลัก 8 ท่า (38 เฟรม) |
| แมวรุ่น | ชุดหลัก 8 ท่า (38 เฟรม) |
| แมวลายสลิด | **มีแล้ว** + ท่าใหม่ `eat`, `sad`, `sick` (13 เฟรม) |
| แมวจรจัด | ชุดหลัก 8 ท่า (38 เฟรม) |
| เอฟเฟกต์ | `evolve_flash`, `hatch_burst`, `heart_pop`, `sparkle`, `zzz` |
| UI | ไอคอนสถานะ 4 ค่า + อาหาร 3 ชนิด + ปุ่มลัดใหม่ |
| ร้านค้า | ไอคอน 16/48/128 + ภาพหน้าจอ |

รวมประมาณ **~145 เฟรมตัวละคร (ไข่ 16 + ลูกแมว/แมวรุ่น/แมวจรจัด 38×3 + ท่าใหม่ของแมวลายสลิด 13) + ~40 เฟรมเอฟเฟกต์ + ~25 ไอคอน**

### รอบ 2 — เพิ่มร่างวิวัฒนาการ
แมวดาว, แมวนักกิน, แมวนักเล่น, แมวจันทร์ — ชุดหลัก 38 เฟรม/ตัว + `special` 4 เฟรม/ตัว (รวมประมาณ 170 เฟรม) + ของแต่งตัว + บ้านเพิ่ม

### รอบ 3 — สมบูรณ์
แมวทอง (ลับ), ชุดเสริม (วิ่ง กระโดด เล่น อาบน้ำ หาว อีโมต) ทุกตัว, ตราความสำเร็จ, ของตกแต่ง, ภาพโปรโมตใหญ่

## 10. Prompt เริ่มต้นสำหรับเครื่องมือสร้างภาพ AI

ใช้กับ ChatGPT (สร้างภาพ), Midjourney, Gemini, Leonardo หรือเครื่องมืออื่น แล้วแนบ **ภาพแผ่นแมวลายสลิดเดิมเป็นภาพอ้างอิงสไตล์** ทุกครั้ง เพื่อให้สไตล์ตรงกัน

### 10.1 โครงหลัก (ใช้ซ้ำ เปลี่ยนเฉพาะ [ตัวละคร] และ [รายการท่า])

```
Pixel-art sprite sheet of a cute chibi cat character, in the exact same art style, outline
thickness, shading and palette family as the reference image. Character: [DESCRIBE CHARACTER].
Layout: a clean grid, one animation per row, frames ordered left to right, each frame fully
separated by at least 24px of empty space, no frame touches the border or another frame.
Rows (top to bottom): [LIST OF ANIMATIONS WITH FRAME COUNTS]. The character faces right in every
frame, the feet stay on the same baseline in every frame of a row (except jumping), and the
character design is perfectly consistent across all frames. Thick dark-brown pixel outline,
two-level flat shading, big sparkling eyes with highlights, small pink blush, soft grey ellipse
shadow under the feet. Transparent background (or plain pure white #FFFFFF if transparency is
not possible). No text, no watermark, no border, no scenery. 1536x1024 or larger.
```

### 10.2 ตัวอย่างการเติม — ลูกแมว (ชุดหลัก)

```
Character: a tiny round baby kitten, oversized head, small rounded ears, short tail, faint tabby
stripes (same brown/cream colors as the reference adult cat but lighter and softer), huge
sparkling eyes, wobbly toddler proportions. About 65px tall on a 1536x1024 sheet.
Rows: 1) IDLE, 6 frames: sitting, ear twitch, blink, tail swish, looking left and right.
2) WALK RIGHT, 6 frames: clumsy toddler waddle. 3) HAPPY, 4 frames: arms up, eyes closed smile,
sparkles. 4) EAT, 5 frames: bends down, chews a fish with puffed cheeks, looks up satisfied.
5) SLEEP, 4 frames: curled into a ball, breathing, floating Z. 6) SAD, 4 frames: drooping ears
and tail, teary eyes. 7) SICK, 4 frames: shivering, pale greenish face, sweat drop.
8) FALL AND LAND, 5 frames: tumbling in the air, flat on the ground, dizzy spinning stars,
getting up, shaking off.
```

### 10.3 ตัวอย่างการเติม — ไข่

```
Character: a cream-colored egg with light brown speckles and a small white highlight, no face,
no limbs. About 70px tall. Rows: 1) EGG IDLE, 4 frames: gently rocking left and right.
2) EGG SHAKE, 4 frames: shaking harder, a small crack appears and grows. 3) EGG HATCH, 8
frames: the crack spreads, shell breaks, bright light, a tiny kitten peeks out with an eggshell
piece on its head.
```

### 10.4 ตัวอย่างการเติม — เอฟเฟกต์แปลงร่าง

```
Pixel-art effect sheet, transparent background. Row: EVOLVE FLASH, 10 frames: a white glowing
cat-shaped silhouette appears, pulses, grows slightly, bursts into a ring of four-point sparkles
and light rays, then fades. Pure white and pale yellow only, no character details inside the
silhouette.
```

### 10.5 เคล็ดลับให้ AI ทำตัวละครคงที่
- สร้าง **แผ่นเดียวต่อตัว** แล้วค่อยแก้ ถ้าสร้างทีละท่าแล้วมาต่อกัน หน้าตาจะเพี้ยน
- ถ้าเครื่องมือรองรับ ให้ล็อก seed หรือใช้ฟีเจอร์ "character reference / style reference"
- ถ้าเฟรมในแถวออกมาไม่เท่ากัน สร้างใหม่เฉพาะแถวนั้นแล้วบอกว่า "same as the row above"
- ถ้าตัวละครกลายเป็น 3D หรือเส้นนุ่ม ให้เติมคำว่า "flat 2D pixel art, hard pixel edges, no anti-aliasing, no gradients, no 3D render"
- ตรวจให้ครบจำนวนเฟรมต่อแถวตามตาราง ถ้าขาด/เกิน ผมตัดผิดได้

## 12. โครงสร้างไฟล์ที่โค้ดจะใช้ (ผมจัดให้หลังได้ภาพ)

```
images/
  cat_adult_tabby/   idle.png  walk_right.png  ... (แถบภาพแนวนอน เฟรมกว้างเท่ากัน)
  cat_egg/           egg_idle.png  egg_shake.png  egg_hatch.png
  cat_kitten/        ...
  cat_young/         ...
  cat_star/          ...
  cat_foodie/ cat_playful/ cat_moon/ cat_stray/ cat_gold/
  fx/                evolve_flash.png  hatch_burst.png  heart_pop.png ...
  ui/                status_hunger.png  food_fish.png  toy_yarn.png  home_wood.png ...
  store/             icon128.png  screenshot1.png  promo_small.png
```

แถบภาพหนึ่งไฟล์ = 1 ท่า เฟรมเรียงซ้ายไปขวา ขนาดเฟรมเท่ากันทุกไฟล์ของตัวละครตัวเดียวกัน
ผมเขียนสคริปต์ตัดจากแผ่นภาพของคุณเป็นแถบภาพเหล่านี้ให้อัตโนมัติ (ตัดตามช่องว่างระหว่างเฟรม ลบพื้นหลัง จัดตำแหน่งตามเส้นฐาน) เหมือนที่ทำกับแมวตัวปัจจุบัน

**ทางลัดประหยัดภาพ:** ท่าเดินซ้ายไม่ต้องวาด ผมเขียนโค้ดให้กลับด้านภาพเดินขวาเอาได้ (ตัวใหม่ทุกตัวไม่ต้องทำ `walk_left` / `run_left`) ถ้าไม่มีรายละเอียดที่ไม่สมมาตร เช่น ลายที่แก้ม ปลอกคอ หรือของแต่งตัวด้านเดียว
