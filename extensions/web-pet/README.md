# Web Pet

Chrome Extension (Manifest V3) น้องกระต่ายใส่หมวกดาว เดินไปมาบนขอบล่างของหน้าเว็บ

## ติดตั้งเพื่อทดสอบ
1. เปิด `chrome://extensions` และเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
3. เปิดเว็บใดก็ได้ (หน้าที่เปิดค้างอยู่ก่อนติดตั้งต้อง refresh) จะเห็นน้องเดินอยู่ด้านล่าง
4. กดไอคอน extension เพื่อเปิด/ปิด

## วิธีเล่น
- **กด** – น้องร่าเริง พูด และปล่อยหัวใจ 💖
- **ลาก** – จับย้ายไปไหนก็ได้ ปล่อยแล้วตกลงมาที่พื้น
- ปล่อยทิ้งไว้ – เดินไปมา นั่งพัก หรือกอดดาวหลับ 💤 เอง (กดเพื่อปลุก)

## ท่าทาง (`images/`)
| ไฟล์ | ใช้เมื่อ |
|---|---|
| `run.png` + `walk.png` | เดิน (สลับสองท่า) |
| `sit.png` | นั่งพัก / หลังโดนกด |
| `star.png` | หลับ |
| `cheer.png` | โดนกด / ถูกลาก / กำลังตก |
| `pile.png` | ตกถึงพื้น |

ภาพทั้งหมดตัดมาจากแผ่นภาพต้นฉบับ (6 ท่า) ขนาด 192×192 พื้นหลังโปร่งใส ถ้าอยากเปลี่ยนตัวละคร ให้แทนที่ไฟล์ใน `images/` ด้วยชื่อเดิม ภาพควรหันไปทางขวา เพราะโค้ดจะกลับด้านเองเมื่อเดินไปทางซ้าย

## โครงสร้าง
- `content.js` – ตัวละคร การเคลื่อนไหว (เดิน/หยุด/หลับ/ตก) และการกด/ลาก ใช้ Shadow DOM ไม่กระทบ CSS ของเว็บ
- `popup.html/css/js` – เปิด/ปิด เก็บค่าด้วย `chrome.storage.sync`
- `manifest.json` – ประกาศ `images/*.png` เป็น web accessible resources เพื่อให้หน้าเว็บโหลดภาพได้
