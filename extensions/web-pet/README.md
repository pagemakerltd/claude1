# Web Pet

Chrome Extension (Manifest V3) ตัวละครน่ารักๆ เดินไปมาบนขอบล่างของหน้าเว็บ

## ติดตั้งเพื่อทดสอบ
1. เปิด `chrome://extensions` และเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
3. เปิดเว็บใดก็ได้ (หน้าที่เปิดค้างอยู่ก่อนติดตั้งต้อง refresh) จะเห็นตัวละครเดินอยู่ด้านล่าง
4. กดไอคอน extension เพื่อเปิด/ปิด หรือเลือกตัวละคร

## วิธีเล่น
- **กด** – ตัวละครกระโดด พูด และปล่อยหัวใจ 💖
- **ลาก** – จับย้ายไปไหนก็ได้ ปล่อยแล้วจะตกลงมาที่พื้น
- ปล่อยทิ้งไว้ – เดินไปมา หยุดพัก หรือหลับ 💤 เอง (กดเพื่อปลุก)

## โครงสร้าง
- `content.js` – ตัวละคร การเคลื่อนไหว (เดิน/หยุด/หลับ/ตก) และการกด/ลาก ใช้ Shadow DOM ไม่กระทบ CSS ของเว็บ
- `popup.html/css/js` – เปิด/ปิดและเลือกตัวละคร เก็บค่าด้วย `chrome.storage.sync` (ใช้ร่วมกันทุกเว็บ)
- ตัวละครเป็น emoji เพิ่มตัวใหม่ได้โดยแก้รายการ `CHARACTERS` ใน `popup.js`
