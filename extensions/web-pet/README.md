# Web Pet

Chrome Extension (Manifest V3) สัตว์เลี้ยงพิกเซล 4 ตัว: น้องแมวลายสลิด น้องหมาชิห์สุ พลูโต (ยอร์คเชียร์เทอร์เรีย) และ Happy (ฮัสกี้/ซามอยด์ขนฟู) อยู่บนขอบล่างของหน้าเว็บ เลือกเลี้ยงกี่ตัวก็ได้

## ติดตั้งเพื่อทดสอบ
1. เปิด `chrome://extensions` และเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
3. เปิดเว็บใดก็ได้ (หน้าที่เปิดค้างอยู่ก่อนติดตั้งต้อง refresh) จะเห็นน้องแมวอยู่ด้านล่าง
4. กดไอคอน extension เพื่อเปิด/ปิด

## วิธีเล่น
- **กด** – น้องตอบสนอง (ดีใจ กอดหัวใจ หรือทำหน้าตาต่างๆ) พูด และปล่อยหัวใจ 💖
- **ลาก** – จับย้ายไปไหนก็ได้ ปล่อยแล้วตกลงมาที่พื้น ล้มกลิ้ง แล้วลุกขึ้นมา
- ปล่อยทิ้งไว้ – น้องสุ่มทำเอง: เดิน วิ่ง นั่ง กระพริบตา นอนหลับ กระโดด เล่นไหมพรม ปีนขึ้นของบนหน้าเว็บ

## 🐱🐶🐕🐺 เลือกสัตว์เลี้ยง และให้เล่นด้วยกัน
กดไอคอน extension แล้วติ๊กที่หัวข้อ **เลือกสัตว์เลี้ยง** ได้กี่ตัวก็ได้ (แมว / หมา / พลูโต / Happy จะเลือกตัวเดียว สองตัว สามตัว หรือทั้งสี่ตัวก็ได้ ติ๊กออกหมดก็ได้) มีผลทันที ตัวที่ไม่ได้เลือกจะหายไปจากหน้าเว็บ

- ถ้ายังมีตัวที่ไม่ได้เลือก ตอนกดที่สัตว์เลี้ยงจะมีปุ่ม ➕ เรียกตัวนั้นมาเพิ่มได้เลย
- ตั้งชื่อสัตว์เลี้ยงแต่ละตัวแยกกันได้ในหน้าตัวเลือก (มีผลกับตอนคุยในแผงแชท) แต่ละตัวมีบุคลิกตอนคุยต่างกัน
- **พลูโตมีไข่อีสเตอร์:** พิมพ์ "พลูโต" (หรือ "Pluto") ลงในช่องจดโน้ต จะมีหัวใจลอยขึ้นจากช่องพิมพ์ และพลูโตดีใจพร้อมหัวใจ (ถ้าไม่ได้เลือกพลูโตไว้ สัตว์เลี้ยงตัวที่เปิดแผงอยู่จะเป็นฝ่ายปล่อยหัวใจแทน) หัวใจจะขึ้นอีกตอนกดบันทึก และโน้ตที่มีชื่อพลูโตจะมี 💖 นำหน้าในรายการ

**เล่นด้วยกัน (ต้องเลือกตั้งแต่ 2 ตัวขึ้นไป)** กดปุ่ม 🤝 หรือรอให้ชวนกันเอง (เปิด/ปิดได้ใน popup) ระบบสุ่มเลือกคู่จากตัวที่ว่างอยู่ ตัวที่ไม่ใช่แมวเป็นฝ่ายเข้าไปชวน ลำดับเหตุการณ์:
1. ตัวที่ชวนวิ่งไปหาอีกตัว แล้วทักชวนเล่น
2. ผลัดกันวิ่งไล่จับ 3 รอบ (ตัวที่จับได้จะกลายเป็นตัวที่ถูกไล่ และได้ออกตัวก่อน)
3. เดินมาเจอกันตรงกลาง: **หมา+แมว** นอนกอดกัน (ภาพที่วาดมาด้วยกัน) ส่วนคู่อื่นนั่งเคียงข้างกัน ดีใจ มีหัวใจลอย
4. แยกย้ายไปทำอย่างอื่นต่อ

ระหว่างเล่น ถ้ากดหรือลากตัวใดตัวหนึ่ง การเล่นจะหยุดทันที แต่ละตัวมีบ้านของตัวเอง (แมว = บ้านไม้หลังคาแดง อยู่ขวา, หมา = กระท่อมหลังคาฟ้า อยู่ซ้าย, พลูโต = บ้านหลังคากรมท่ามีป้าย PLUTO อยู่กลาง, Happy = บ้านหลังคาเหลืองมีหน้ายิ้ม) ลากย้ายได้

**ของเล่น:** 🧶 ไหมพรม (แมวชอบ) · 🦴 กระดูก (หมา พลูโต และ Happy ชอบ) · 🐟 ปลา และ 🎾 ลูกบอล (ชอบทุกตัว ตัวที่อยู่ใกล้กว่าและว่างจะไปเล่นก่อน)

## บ้าน โน้ต เว็บที่จำไว้ และคุยกับน้อง
กดที่น้อง จะมีปุ่มลัด 💬 คุย / 📝 โน้ต / 🌐 เว็บ / 🏠 นอน หรือเปิดจาก popup ของ extension ก็ได้

- **🏠 บ้านของน้อง** – บ้านหลังเล็กอยู่ที่ขอบล่างของหน้าจอ เวลาน้องง่วงจะเดินเข้าไปนอนเอง (มี z z Z ลอยขึ้นมา) กดที่บ้านตอนว่างเพื่อเรียกน้องไปนอน กดตอนน้องนอนอยู่เพื่อปลุก ลากบ้านไปวางตรงไหนก็ได้ ตำแหน่งจะถูกจำไว้ ปิดบ้านได้ใน popup
- **🤾 โยนน้องไปบนของในหน้าเว็บ** – ลากน้องแล้วปล่อยตอนเมาส์กำลังเคลื่อนที่ น้องจะลอยตามแรงที่โยน ถ้าตกลงตรงหัวข้อ รูป ปุ่ม ย่อหน้า ฯลฯ น้องจะลงจอดยืนบนนั้น ถ้าไม่ตรงก็ลงพื้น (ปล่อยโดยไม่ขยับเมาส์ = ปล่อยให้ตกลงพื้นตรงๆ)
- **📝 โน้ต** – จดโน้ตได้ ติ๊กให้ผูกกับเว็บนี้เพื่อเก็บชื่อเว็บและลิงก์ไว้กับโน้ต ดูแยกได้ระหว่างโน้ต "เว็บนี้" กับ "ทั้งหมด"
- **🌐 เว็บที่จำไว้** – กด "จำเว็บนี้ไว้" แล้วเมื่อกลับมาเว็บนี้อีก น้องจะทักว่ากลับมาครั้งที่เท่าไหร่ และมีกี่โน้ต ดูรายการเว็บที่จำไว้ (จำนวนครั้ง ครั้งล่าสุด ลิงก์) ได้ในแท็บนี้ น้องนับจำนวนครั้งเฉพาะเว็บที่เลือกจำไว้เท่านั้น ไม่ได้บันทึกประวัติการเข้าเว็บอื่น
- **💬 คุยกับน้อง** – พิมพ์คุยกับน้องแมวได้ ใช้ Claude ตอบ ต้องตั้งค่า API key ก่อน (คลิกขวาที่ไอคอน extension → ตัวเลือก หรือกด "ตั้งค่า API key" ใน popup) ประวัติการคุยล่าสุดถูกเก็บไว้ในเครื่อง

ข้อมูลโน้ต เว็บที่จำไว้ และประวัติแชท เก็บใน `chrome.storage.local` ของเบราว์เซอร์นี้ ไม่ซิงก์ข้ามเครื่อง

### เรื่องความเป็นส่วนตัวของการคุย
- ข้อความที่พิมพ์คุยถูกส่งไปที่ Anthropic (api.anthropic.com) พร้อมชื่อหน้าและโดเมนของเว็บที่เปิดอยู่ ไม่ส่งเนื้อหาของหน้าเว็บ
- โน้ตและรายชื่อเว็บที่จำไว้ **ไม่ถูกส่ง** เว้นแต่คุณติ๊ก "ให้น้องอ่านโน้ตของเว็บปัจจุบันและรายชื่อเว็บที่จำไว้" ในหน้าตัวเลือก
- API key อยู่ที่ service worker (`background.js`) เท่านั้น ไม่เคยถูกส่งเข้าไปในหน้าเว็บ
- ทุกข้อความมีค่าใช้จ่ายตามโมเดลที่เลือก (ค่าเริ่มต้น `claude-opus-5-5` ถ้าอยากถูกและเร็วลงให้ใส่ `claude-haiku-4-5` ในหน้าตัวเลือก)

## ให้น้องมีปฏิสัมพันธ์กับสิ่งต่างๆ
กดไอคอน extension จะมีตัวเลือกเหล่านี้

- **🧶 ไหมพรม / 🐟 ปลา** – โยนของเล่นลงบนหน้าเว็บ ของตกลงมากระเด้งกระดอน แล้วน้องวิ่งไปเล่น (ไหมพรม) หรือกิน (ปลา) ลากของเล่นด้วยเมาส์แล้วปล่อยเพื่อโยนได้ ไม่ต้องรอให้ตกเอง
- **วิ่งตามเมาส์** – น้องเดินหรือวิ่งตามเคอร์เซอร์ไปมาในแนวนอน (ปิดไว้เป็นค่าเริ่มต้น)
- **ปีนขึ้นของบนหน้าเว็บ** – น้องสุ่มกระโดดขึ้นไปยืนบนหัวข้อ รูป ปุ่ม ย่อหน้า ฯลฯ ที่มองเห็นอยู่ แล้วเดินไปมา นั่ง นอน บนนั้น เลื่อนหน้าเว็บแล้วน้องเลื่อนตามของที่ยืนอยู่ ถ้าของนั้นหายไปจากจอหรือถูกซ่อน น้องจะตกลงมา (เปิดไว้เป็นค่าเริ่มต้น)

ทั้งหมดทำงานในหน้าเว็บเท่านั้น ไม่เปลี่ยนแปลงหรือคลิกอะไรในเว็บ

## แอนิเมชัน (`images/cat/`, `images/dog/`, `images/pluto/`, `images/happy/`)
แต่ละไฟล์คือแถบภาพ (sprite strip) เรียงเฟรมต่อกันในแนวนอน ทุกเฟรมขนาด 234×141 พื้นหลังโปร่งใส ตัดมาจากแผ่นภาพต้นฉบับ

| ไฟล์ | เฟรม | ใช้เมื่อ |
|---|---|---|
| `idle` / `blink` | 7 / 4 | นั่งอยู่เฉยๆ |
| `walk_right` / `walk_left` | 7 / 7 | เดิน |
| `run_right` / `run_left` | 6 / 5 | วิ่ง |
| `jump` | 6 | กระโดด / ตอนถูกลาก |
| `fall_land` | 5 | ตก ล้ม และลุก |
| `play` | 5 | เล่นไหมพรม |
| `sit_lie` | 8 | นอนหลับ |
| `happy` / `special` / `emote` | 3 / 4 / 11 | ตอบสนองเมื่อถูกกด |

จำนวนเฟรมของแต่ละแถบกำหนดใน `FRAME_COUNT` ของ `content.js` ถ้าเปลี่ยนภาพ ต้องแก้ตัวเลขนี้และ `CELL_W`/`CELL_H` ให้ตรง ปรับขนาดน้องได้ที่ `SCALE`

## โครงสร้าง
- `species.js` – ข้อมูลของแมว หมา พลูโต และ Happy: แถบภาพ ท่าทาง คำพูด บ้าน (เพิ่มสัตว์ชนิดใหม่ที่นี่)
- `panel.js` – แผงโน้ต เว็บที่จำไว้ และแชท (เก็บข้อมูลด้วย `chrome.storage.local`)
- `background.js` – เรียก Claude API ให้แผงแชท (service worker เก็บ API key)
- `options.html/js` – ตั้งค่า API key โมเดล ชื่อน้อง
- `content.js` – สัตว์เลี้ยงแต่ละตัว (class `Pet`) ของเล่น การเล่นด้วยกัน ระบบแอนิเมชัน การเคลื่อนไหว (เดิน/วิ่ง/กระโดด/หลับ/ตก) และการกด/ลาก ใช้ Shadow DOM ไม่กระทบ CSS ของเว็บ
- `popup.html/css/js` – เปิด/ปิด เก็บค่าด้วย `chrome.storage.sync`
- `manifest.json` – ประกาศ `images/cat/*.png` เป็น web accessible resources เพื่อให้หน้าเว็บโหลดภาพได้
