# ใบเสนอราคา / วางบิล (Web App)

เปิด `index.html` ใน Chrome/Edge ได้เลย (ไม่ต้องติดตั้ง ใช้ออฟไลน์ได้) — ข้อมูลเก็บในเบราว์เซอร์ (IndexedDB)
ต้องมีโฟลเดอร์ `vendor/` อยู่ข้างไฟล์ (ไลบรารีอ่านไฟล์ Excel: SheetJS 0.18.5, Apache-2.0)

## ฟีเจอร์
- เอกสาร 4 ชนิด: ใบเสนอราคา → ใบวางบิล → ใบแจ้งหนี้/ใบกำกับภาษี → ใบเสร็จ (ปุ่ม "แปลงเป็น…" ส่งต่อข้อมูลและเลขอ้างอิง)
- เลขที่อัตโนมัติ เช่น QT2026-0001 (ตั้งคำนำหน้าและ ค.ศ./พ.ศ. ได้)
- VAT: ยังไม่รวม / รวมแล้ว (แยกออก) / ไม่มี, อัตราตั้งได้, ยกเว้น VAT รายบรรทัดได้
- ส่วนลดรายบรรทัด (% หรือบาท) และท้ายบิล, หัก ณ ที่จ่าย 1/2/3/5%, ยอดเป็นตัวอักษรไทย
- เงินคิดเป็นสตางค์ (จำนวนเต็ม) ไม่มีปัญหาทศนิยมคลาดเคลื่อน
- พิมพ์ A4 / บันทึก PDF ผ่านปุ่ม 🖨, โลโก้ สีเอกสาร บัญชีธนาคาร
- สำรอง/กู้คืนข้อมูลเป็น JSON, ส่งออกรายการเอกสารเป็น Excel

## นำเข้าจาก Excel (.xlsx/.xls) หรือ CSV
อ่านแถวแรกเป็นหัวคอลัมน์ ชื่อคอลัมน์ภาษาไทยหรืออังกฤษก็ได้ (CSV ไทยทั้ง UTF-8 และ Excel เก่า TIS-620 ได้)
- **ลูกค้า**: ชื่อ, ที่อยู่, เลขผู้เสียภาษี, สาขา, โทร, อีเมล, เครดิต (ชื่อซ้ำ = อัปเดตของเดิม)
- **สินค้า**: รหัส, ชื่อ, หน่วย, ราคา, VAT (มี/ไม่มี)
- **รายการในเอกสารที่เปิดอยู่**: ชื่อ/รายการ, จำนวน, หน่วย, ราคา, ส่วนลด (เช่น `10%` หรือ `100`), VAT
- **เอกสารหลายใบพร้อมกัน**: 1 แถว = 1 รายการ + คอลัมน์ กลุ่ม, ลูกค้า, วันที่ (แถวกลุ่มเดียวกันรวมเป็นใบเดียว)
ปุ่ม "ดาวน์โหลดไฟล์ตัวอย่าง" ในหน้าลูกค้า/สินค้า

> โปรแกรมช่วยจัดทำเอกสาร ควรให้ผู้ทำบัญชีตรวจแบบฟอร์มใบกำกับภาษีก่อนใช้จริง
