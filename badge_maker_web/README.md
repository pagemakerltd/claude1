# Badge Maker (Web App)

ไฟล์เดียว `index.html` — ไม่ต้องติดตั้ง ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลเก็บในเบราว์เซอร์ (IndexedDB)

เปิดใช้: ดับเบิลคลิก `index.html` (แนะนำ Chrome/Edge) หรืออัปโหลดขึ้น static hosting (GitHub Pages ฯลฯ)
ทดสอบในเครื่อง: `python -m http.server` แล้วเปิด http://localhost:8000

ฟีเจอร์เหมือนฉบับ Windows: สร้าง Template, เพิ่ม/ลบช่องข้อความ-รูป, ลาก/ย่อขยาย, ฟอนต์/ขนาด/สี,
ฐานข้อมูลข้อความ+รูป, นำเข้ารูปหลายไฟล์/โฟลเดอร์/CSV, ส่งออก ZIP (PNG/JPG) และพิมพ์/PDF หลายใบต่อหน้า A4
เพิ่ม: สำรอง/กู้คืนข้อมูลเป็นไฟล์ JSON (ควรสำรองเป็นระยะ เพราะข้อมูลผูกกับเบราว์เซอร์นี้)
