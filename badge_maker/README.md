# Badge Maker — โปรแกรมสร้างป้ายชื่อ / บัตร แบบ Batch (Windows)

Python + Tkinter + Pillow + SQLite (ไม่ต้องใช้อินเทอร์เน็ตตอนใช้งาน)

## ติดตั้ง / รัน
1. ติดตั้ง Python 3.10+ จาก python.org (ติ๊ก *Add to PATH*)
2. ดับเบิลคลิก `run.bat`  (หรือ `pip install -r requirements.txt` แล้ว `python app.py`)
3. อยากได้ไฟล์ `.exe` ดับเบิลคลิกเปิดได้เลย → รัน `build_exe.bat` จะได้ `dist\BadgeMaker.exe`

## วิธีใช้
1. **ออกแบบ Template** – กด `＋ ใหม่` เลือกขนาดบัตร (mm/dpi) → ใส่รูปพื้นหลัง/สีพื้น →
   `＋ ข้อความ` / `＋ รูปภาพ` เพิ่มกี่จุดก็ได้ ลากกรอบเพื่อย้าย ลากมุมขวาล่างเพื่อปรับขนาด
   ปรับฟอนต์ ขนาด สี การจัดวาง ในแผงขวา (ช่องรูป: cover/contain/stretch, สี่เหลี่ยม/มน/วงกลม)
2. **ข้อมูล** – เพิ่มทีละแถว, `นำเข้ารูปทั้งโฟลเดอร์` (ชื่อไฟล์ → ชื่อคน, รูป → ช่องรูป) หรือ `นำเข้า CSV`
   (หัวคอลัมน์ = ชื่อช่อง, ช่องรูปใส่ path ไฟล์) ข้อมูล+รูปถูกเก็บในฐานข้อมูล SQLite ของโปรแกรม
3. **สร้าง Batch** – ส่งออกเป็นไฟล์ PNG/JPG แยกทีละคน หรือจัดหลายใบลง A4 เป็น PDF พร้อมตัด

ข้อมูลทั้งหมดอยู่ที่ `%APPDATA%\BadgeMaker` (สำรองข้อมูล = คัดลอกโฟลเดอร์นี้)
ฟอนต์เพิ่มเติม: ปุ่ม *เพิ่มไฟล์ฟอนต์...* หรือวางไฟล์ในโฟลเดอร์ `fonts` ข้างใน

หมายเหตุ: ขนาดฟอนต์เป็นพิกเซลของ Template (300 dpi: 12pt ≈ 50 px) ภาษาไทยแนะนำ Tahoma / Leelawadee UI / TH Sarabun New
